Who We Are

This is a practice Angular application created to learn the basics of components, routing, styling, and Angular structure. The goal is to understand how real projects are built step by step.

What This Project Includes

  • Angular Components
  • Routing & Navigation
  • Reusable HTML Sections
  • Basic UI Design

Why Practice?

Practice helps build confidence and improve development skills. Creating pages like Home, About, and Contact gives a clear idea of how Angular works in a real project environment.
